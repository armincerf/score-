# score

iPhone + Apple Watch table-tennis scorer with match recording, highlight reels and
on-device AI summaries. iOS 27 / watchOS 27, Swift 6.

```
make setup   # one-time: tools, git hooks, Xcode agent skills
make check   # lint + build + test
```

See [AGENTS.md](AGENTS.md) for the architecture, conventions and commands (written for
humans and coding agents alike).
